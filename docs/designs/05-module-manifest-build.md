## 2. In-Scope Paths (exactly 3)

| # | Path | Kind | Produced by |
|---|------|------|-------------|
| 1 | `src/BugFreeUmbrella/BugFreeUmbrella.psd1` | Manifest (PSD1 data file) | Generated/updated by `tools/Build-Module.ps1` + committed; hand-edited only for GUID/PrivateData |

**Excluded:** `*.Format.ps1xml`, `en-US/` help (platyPS later), any file under `scripts/` (builder reads catalog, never rewrites scripts).

### 3.2 `FunctionsToExport` — Auto-Generated (358 entries)

**Source of truth:** `scripts/.catalog/metadata.json` → `scripts[].path` + `scripts[].category`.

**Naming algorithm:**

```
For each s in catalog.scripts:
  categoryParts = s.category -split '/'
  leafDir       = categoryParts[-1]                     # e.g. 'Fix-TeamsCache'
  stem          = [IO.Path]::GetFileNameWithoutExtension(s.name)
  if stem -match '^(detect|remediate|Detect|Remediate)$':
      # Generic pair — use leaf dir as noun
      # detect    -> Test-<Noun>
      # remediate -> Invoke-<Noun>
      # Fix-TeamsCache/detect.ps1    -> Test-TeamsCache
      # Fix-TeamsCache/remediate.ps1 -> Invoke-TeamsCache
      noun = leafDir -replace '^Fix-','' -replace '^Check-',''
      # Keep domain clarity: TeamsCache not FixTeamsCache
      functionName = if stem -match '^detect$' -i { "Test-$noun" } else { "Invoke-$noun" }
      # Winget special: suffix Winget to avoid collision
      if s.category -like '*/winget/*': functionName += 'Winget'  # Test-FirefoxWinget
  else:
      # Meaningful stem — use directly if Approved Verb, else prefix Invoke-
      functionName = ConvertTo-ApprovedVerb -Stem $stem
```

**Approved-Verb enforcement:** All 358 names MUST use approved verbs. Build fails on unapproved verb. `Fix-*`→`Repair-*` or `Invoke-*`, `Check-*`→`Test-*`.

**Collision check:** `assert $names.Count -eq ($names | Sort -Unique).Count`; on collision fail with diagnostic.

**Export-ModuleMember:** PSM1 ends with `Export-ModuleMember -Function $FunctionsToExport`; manifest and PSM1 lists MUST match (builder verifies).

### 3.3 PrivateData.PSData Detail

| Key | Value | Notes |
|-----|-------|-------|
| `Tags` | 8 tags above | Gallery search |
| `LicenseUri` | `.../blob/main/LICENSE` | Apache-2.0 |

### 3.4 MUST NOT Contain

- `RequiredModules` with pinned versions
- `ScriptsToProcess` (PSM1 handles loading)
- Hardcoded secrets / `PSGALLERY_API_KEY`
- Wildcard `FunctionsToExport = '*'` (explicit list required; satisfies `PSUseToExportFieldsInManifest`)

## 4. Loader Spec — `src/BugFreeUmbrella/BugFreeUmbrella.psm1`

### 4.1 Decision: Build-Time Proxy Generation (NOT dynamic dot-sourcing)

**Rejected — runtime dot-source loop:**

```powershell
# REJECTED — pollutes module scope, no ShouldProcess passthrough, not PSSA-analyzable
Get-ChildItem $PSScriptRoot/../../scripts -Filter *.ps1 -Recurse | ForEach-Object { . $_.FullName }
```

**Chosen — build-time generated proxy functions:**

Builder emits one `function` block per catalog entry. Each wrapper has the exported name, declares `SupportsShouldProcess`, and invokes the backing script via `& $PSScriptRoot/../../scripts/<path>` with splatted args. Gives explicit exports, PSSA-analyzable, no scope pollution, gallery-friendly.

### 4.2 PSM1 Skeleton

```powershell
#Requires -Version 5.1
<#
.SYNOPSIS
    BugFreeUmbrella module loader — 358 proxy functions generated by tools/Build-Module.ps1.

.DESCRIPTION
    Each exported function is a thin wrapper that invokes the corresponding
    script under scripts/ via call operator (&) with ShouldProcess passthrough.
    Do not edit by hand — regenerate with: pwsh -File tools/Build-Module.ps1

.NOTES
    File Name  : BugFreeUmbrella.psm1
    Author     : Carme99
    Prerequisite: PowerShell 7.0+ recommended (5.1 minimum for import)
    Version    : 5.0.0
#>
Set-StrictMode -Version Latest
$ErrorActionPreference = 'Stop'

$script:ScriptsRoot = (Resolve-Path (Join-Path $PSScriptRoot '../../scripts')).Path

if ($PSVersionTable.PSVersion.Major -lt 7) {
    Write-Warning 'BugFreeUmbrella is tested on PowerShell 7+. Some scripts may not work on Windows PowerShell 5.1.'
}

#region Generated Functions — DO NOT EDIT BETWEEN MARKERS
# BEGIN GENERATED — 358 functions

function Test-TeamsCache {
    <#
    .SYNOPSIS
        Wrapper for endpoints/devices/proactive-remediations/Fix-TeamsCache/detect.ps1
    .DESCRIPTION
        Proxies to scripts/endpoints/devices/proactive-remediations/Fix-TeamsCache/detect.ps1.
        Original synopsis: Checks and reports Teams cache health.
    .PARAMETER WhatIf
        Shows what would happen without executing.
    .EXAMPLE
        Test-TeamsCache -Verbose
    .NOTES
        Backing script: scripts/endpoints/devices/proactive-remediations/Fix-TeamsCache/detect.ps1
        Category: endpoints/devices/proactive-remediations/Fix-TeamsCache
    #>
    [CmdletBinding(SupportsShouldProcess, ConfirmImpact = 'Medium')]
    param(
        [Parameter(ValueFromRemainingArguments)]
        [object[]] $Args
    )
    begin { $boundParams = $PSBoundParameters }
    process {
        $target = Join-Path $script:ScriptsRoot 'endpoints/devices/proactive-remediations/Fix-TeamsCache/detect.ps1'
        if ($PSCmdlet.ShouldProcess($target, 'Invoke script')) {
            & $target @boundParams @Args
        }
    }
}

function Invoke-TeamsCache {
    <#
    .SYNOPSIS
        Wrapper for endpoints/devices/proactive-remediations/Fix-TeamsCache/remediate.ps1
    #>
    [CmdletBinding(SupportsShouldProcess, ConfirmImpact = 'Medium')]
    param(
        [Parameter(ValueFromRemainingArguments)]
        [object[]] $Args
    )
    process {
        $target = Join-Path $script:ScriptsRoot 'endpoints/devices/proactive-remediations/Fix-TeamsCache/remediate.ps1'
        if ($PSCmdlet.ShouldProcess($target, 'Invoke script')) {
            & $target @PSBoundParameters @Args
        }
    }
}

# ... 356 more, alphabetically sorted ...
# END GENERATED
#endregion

$script:FunctionsToExport = @(
    'Get-DeviceComplianceReport'
    'Invoke-TeamsCache'
    'Test-TeamsCache'
    # ... 358 total
)
Export-ModuleMember -Function $script:FunctionsToExport
```

### 4.3 Parameter Forwarding

| Backing script has | Wrapper does |
|----|----|
| `[CmdletBinding()]` + typed `param()` | Mirror params with same names/types/mandatory at build time (via `Language.Parser` as `Build-Catalog.ps1` does) |
| No CmdletBinding / simple params | Single `[Parameter(ValueFromRemainingArguments)] [object[]] $Args` + splat |
| Needs ShouldProcess | Wrapper declares `SupportsShouldProcess`; if `-WhatIf` and target lacks it, wrapper skips `&` and emits `What if:` itself |

Wrappers use `process {}` so pipeline input flows. `ValueFromPipeline` attributes mirrored when present.

### 4.4 Style Constraints

- UTF-8 with BOM, CRLF, 4-space indent
- Comment-based help on every generated function (`.SYNOPSIS` + `.NOTES` with backing path)
- Approved Verbs enforced (enable `PSUseApprovedVerbs` for `src/BugFreeUmbrella/` even if globally excluded)
- PSSA 0 (no `catch {}` etc.; generated code has no catches)
- No `Write-Host` in wrappers

## 5. Build Pipeline — `tools/Build-Module.ps1`

### 5.1 Synopsis & Parameters

```powershell
<#
.SYNOPSIS
    Builds src/BugFreeUmbrella/ from scripts/.catalog/metadata.json and CHANGELOG.md.
.DESCRIPTION
    Reads catalog (358), derives 358 Approved-Verb names, generates psm1+psd1,
    validates with Test-ModuleManifest + PSScriptAnalyzer, optionally dry-run publishes.
.PARAMETER Validate
    Fail if on-disk psd1/psm1 are stale (CI gate). Does not write.
.PARAMETER Publish
    After build, run Publish-Module -WhatIf (dry-run). Real publish needs PSGALLERY_API_KEY.
.EXAMPLE
    pwsh -File tools/Build-Module.ps1
.EXAMPLE
    pwsh -File tools/Build-Module.ps1 -Validate
.EXAMPLE
    pwsh -File tools/Build-Module.ps1 -Publish -WhatIf
#>
[CmdletBinding(SupportsShouldProcess)]
param(
    [switch] $Validate,
    [switch] $Publish
)
```

Prereq guard: `if ($PSVersionTable.PSVersion.Major -lt 7) { throw }`.

### 5.2 Five Build Steps

#### Step 1 — Validate Prerequisites & Resolve Inputs
- Assert `scripts/.catalog/metadata.json` exists (else suggest `tools/Build-Catalog.ps1`).
- Parse `CHANGELOG.md` `## [Unreleased]` / `## [5.0.0]` for `ModuleVersion` via regex `## \[(?<ver>\d+\.\d+\.\d+)\]`; fallback `5.0.0` for Hurricane. Fail if not `5.0.0`.
- Resolve `$RepoRoot`, `$OutDir = src/BugFreeUmbrella`.

#### Step 2 — Derive Function Names from Catalog
- Load JSON; warn (not fail) if `totalScripts -ne 358`.
- Apply naming algorithm (§3.2) → `$functionsToExport` sorted alphabetically.
- Map `functionName -> @{ Path; Category; Synopsis; Params }`.
- Detect collisions; fail with duplicate list.

#### Step 3 — Generate `BugFreeUmbrella.psm1` and `BugFreeUmbrella.psd1`
- **PSM1:** Render skeleton (§4.2) + loop over map emitting each `function` block via here-string template. Write with `[IO.File]::WriteAllText(..., [Text.UTF8Encoding]::new($true))` + CRLF normalization. In `-Validate`, diff instead of write.
- **PSD1:** Render hashtable (§3.1) with `ModuleVersion` + `FunctionsToExport`. Preserve GUID if on-disk PSD1 exists, else `[guid]::NewGuid()`. `ReleaseNotes` from CHANGELOG (500-char truncated, single-lined). Same BOM/CRLF write.
- Ensure `$OutDir` exists.

#### Step 4 — Validate Artifacts
- `Test-ModuleManifest -Path $OutDir/BugFreeUmbrella.psd1 -ErrorAction Stop` — MUST pass.
- `Invoke-ScriptAnalyzer -Path $OutDir/BugFreeUmbrella.psm1 -Severity Error,Warning` — MUST be 0.
- Smoke import: `Import-Module $OutDir/BugFreeUmbrella.psd1 -Force -PassThru` + `(Get-Command -Module BugFreeUmbrella).Count -eq 358`.

#### Step 5 — Optional Publish (dry-run by default)
- Only if `-Publish`.
- Default: `Publish-Module -Path $OutDir -Repository PSGallery -WhatIf` (no key needed).
- Real publish (no `-WhatIf`): require `env:PSGALLERY_API_KEY`; throw if missing; call `Publish-Module -NuGetApiKey $env:PSGALLERY_API_KEY` with masked logging.
- CI: `-Validate` + `-Publish -WhatIf` on PRs; real publish only on `refs/tags/v5.*`.

### 5.3 CI Integration

```yaml
build-module:
  runs-on: ubuntu-latest
  steps:
    - uses: actions/checkout@v4
    - name: Build module (validate)
      shell: pwsh
      run: pwsh -File tools/Build-Module.ps1 -Validate
    - name: Dry-run publish
      shell: pwsh
      run: pwsh -File tools/Build-Module.ps1 -Publish -WhatIf
```

Builder MUST be idempotent: two runs without catalog change → byte-identical outputs (sorted, deterministic GUID).

## 6. Edge Cases — Duplicate Basenames & Naming

### 6.1 Scale

| Basename | Count |
|----------|-------|
| `detect.ps1` | 94 |
| `remediate.ps1` | 92 |
| `Detect.ps1` / `Remediate.ps1` | 5 each |
| `Update-M365Apps.ps1` | 2 |

Naive stem-as-name → ~190 collisions on `detect`/`remediate`.

### 6.2 Disambiguation Rules (LOCKED)

**Rule 1 — Generic stems (`detect`/`remediate`):**
```
Fix-TeamsCache/detect.ps1      → Test-TeamsCache
Fix-TeamsCache/remediate.ps1   → Invoke-TeamsCache
Check-BatteryHealth/detect.ps1 → Test-BatteryHealth
_templates/detect.ps1          → skip (template) or Test-TemplateHealth
Winget: browsers/Firefox/detect.ps1 → Test-FirefoxWinget (suffix Winget)
```
Noun = leaf dir stripped of `Fix-`/`Check-` prefix, PascalCased. If stripping causes collision, keep full leaf (`Test-FixFoo` vs `Test-CheckFoo`).

**Rule 2 — Meaningful stems:**
Use stem directly if approved verb; else `Invoke-` prefix. On stem collision (e.g., 2× `Update-M365Apps.ps1`), append PascalCased parent category:
```
collaboration/.../Update-M365Apps.ps1 → Update-M365Apps
winget/.../Update-M365Apps.ps1        → Update-M365AppsWinget
```

**Rule 3 — Final fallback:**
Numeric suffix `_2`, `_3` + `Write-Warning`; for 358 this is treated as error to force manual rename.

### 6.3 Noun Construction

- `Fix-DNSCache` → `DnsCache` → `Test-DnsCache` / `Invoke-DnsCache`
- Full backing path always in `.NOTES` so `Get-Help` reveals origin
- Case-insensitive dedup: `detect.ps1` vs `Detect.ps1` lowercased for collision check

## 8. Open Decisions Locked

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Dot-source vs proxy | **Proxy (build-time)** | Isolation, ShouldProcess, PSSA |
| Param forwarding | Mirror typed params or `ValueFromRemainingArguments` | Fidelity without brittleness |
| detect verb | `Test-` | Approved verb for check |
| remediate verb | `Invoke-` | Avoids unapproved `Fix-` |
| Winget suffix | `Winget` | Collision avoidance |
| GUID | Generate once, preserve | Gallery identity stable |
| Secrets | `env:PSGALLERY_API_KEY` | Never hardcoded |
| Encoding | UTF-8 BOM + CRLF, 4-space | Repo convention |
| Publish default | `-WhatIf` dry-run | Safe CI |

## 9. Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| 358 functions → ~14k-line PSM1 | Acceptable (<500ms load); future split into `Public/` if >500 funcs |
| Param drift | Builder re-parses each run; `-Validate` catches |
| Unapproved verbs in stems | Builder maps `Fix`→`Invoke`, `Check`→`Test` with log |
| GUID loss | Committed PSD1 preserves GUID |
| Gallery name taken | Check `Find-Module`; fallback `BugFreeUmbrella-Carme99` |
