> **Status:** Draft — Foundation phase (design only, no code)
> **Version target:** 5.0.0 Hurricane (next after 4.4.0 Nimbus)
> **Scope:** `Tests/Module.Tests.ps1` · `Tests/Catalog.Tests.ps1` · `Tests/CLI.Tests.ps1` · `Tests/Pester.Config.psd1`
> **Author:** DesignTests agent — 2026-08-20

## 1. Goal

Expand the 6 existing `It` blocks (WARP 66 lines, Update-M365Apps 2, Winget 1, plus `Tests/Common`/`Tests/CI` helpers) — three of which are informational failures — to **30+ passing `It` blocks** by adding **26 new `It` blocks (10 + 8 + 8)** across three new Pester 5 files. Update `Tests/Pester.Config.psd1` to collect coverage from both `scripts/` and the new `src/BugFreeUmbrella/` module and to emit JaCoCo + NUnitXml with an **informational 30% threshold** for 5.0. Design must be consumable by Implementation without additional research.

Constraints that apply to every file below:

* PowerShell 7+ (`#Requires -Version 7.0` or `#Requires -Modules Pester` header).
* PSSA Errors fail CI — 4-space indent, CRLF + BOM, comment-based help required, Approved Verbs only (`.vscode/PSScriptAnalyzerSettings.psd1` severity `Error`/`Warning`, `Error` gates).
* `Set-StrictMode -Version Latest` + `$ErrorActionPreference = 'Stop'` in test helpers where appropriate.
* Pester 5.5.0+ idioms (`Describe`/`Context`/`It`/`BeforeAll`/`AfterAll`/`BeforeEach`/`Mock`/`Should -Invoke`).

## 3. Tests/Pester.Config.psd1 — Update Spec

### 3.1 Current file (51 lines)

```powershell
@{

    CodeCoverage = @{ Enabled = $true; Path = @('./scripts'); OutputPath = './Tests/CodeCoverage.xml'; OutputFormat = 'JaCoCo'; OutputEncoding = 'UTF8'; RecursePaths = $true }
    TestResult   = @{ Enabled = $true; OutputPath = './Tests/TestResults.xml'; OutputFormat = 'NUnitXml'; OutputEncoding = 'UTF8' }
    Output       = @{ Verbosity = 'Detailed'; StackTraceVerbosity = 'Filtered'; CIFormat = 'Auto' }
    Should       = @{ ErrorAction = 'Stop' }
    Filter       = @{ Tag = @(); ExcludeTag = @('Integration'); Line = @(); FullName = @() }
}
```

### 3.2 Required diff

```diff
 CodeCoverage = @{
     Enabled = $true
-    Path = @('./scripts')
+    Path = @('./scripts', './src/BugFreeUmbrella')
     OutputPath = './Tests/CodeCoverage.xml'
     OutputFormat = 'JaCoCo'
     OutputEncoding = 'UTF8'
     RecursePaths = $true
+    # 5.0 Hurricane: informational threshold only — does NOT gate CI.
+    # Future 5.1 will raise to 50% and gate.
+    CoveragePercentTarget = 30
 }
 TestResult = @{
     Enabled = $true
     OutputPath = './Tests/TestResults.xml'
     OutputFormat = 'NUnitXml'
     OutputEncoding = 'UTF8'
 }
+# Run ordering — new files must be discoverable via Run.Path = './Tests' (recursive).
+# No Filter.Tag change.
```

### 3.3 Semantics

* `Enabled = $true` — always on, even locally.
* `Path` — now two roots. Pester will merge coverage across both. `src/BugFreeUmbrella/BugFreeUmbrella.psm1` is a thin loader that dot-sources public functions; coverage intentionally counts it (loader lines are trivially covered by import tests). If Pester's JaCoCo chokes on duplicate basenames, Implementation shall set `SingleHitBreakpoints = $true` (Pester 5.4+) or exclude `*.psd1` from coverage via `ExcludePath`.
* `CoveragePercentTarget = 30` — **informational only**. CI (`.github/workflows/validate-powershell.yml` job `test`) MUST NOT `exit 1` on below-threshold. Implementation adds a `Write-Warning "Coverage $($result.CodeCoverage.CoveragePercent)% below target 30% — informational"` after `Invoke-Pester`. The `validate-powershell.yml` comment `# Coverage is enabled … allow low coverage to pass` remains. Future gate is out of scope.
* `OutputFormat = 'JaCoCo'` and `NUnitXml` are consumed by `upload-artifact` (`Tests/CodeCoverage.xml`, `Tests/TestResults.xml`). Do not change `OutputPath`.
* Existing keys (`Run.PassThru`, `Should.ErrorAction`, `Filter.ExcludeTag = @('Integration')`, `Debug.*`) are preserved verbatim.

### 3.4 Edge — Config load failure

If `Import-PowerShellDataFile -Path ./Tests/Pester.Config.psd1` throws (syntax error), Implementation must surface the parse error with `throw "Pester.Config.psd1 parse failed: $($_.Exception.Message)"` rather than silently defaulting. Test runner snippet (for docs, not code):

```powershell
$config = Import-PowerShellDataFile -Path ./Tests/Pester.Config.psd1
$pesterConfig = New-PesterConfiguration -Hashtable $config
$result = Invoke-Pester -Configuration $pesterConfig
```

### 4.1 Header and scaffolding

```powershell
#Requires -Modules Pester

<#

    Validates the BugFreeUmbrella PowerShell module (5.0 Hurricane) — import, manifest, exports, PSSA.

.DESCRIPTION

.NOTES
    File Name  : Module.Tests.ps1

#>

BeforeAll {

    $manifestPath = Join-Path $repoRoot 'src/BugFreeUmbrella/BugFreeUmbrella.psd1'

```

* Encoding: UTF-8 with BOM, CRLF, 4-space indent.
* Must `Remove-Module BugFreeUmbrella -ErrorAction SilentlyContinue` in `BeforeAll` and `AfterAll` so re-runs are idempotent.
* If `src/BugFreeUmbrella` does not exist yet (Implementation ordering), the first It fails with actionable message `"Module manifest not found at $manifestPath — run DesignModule implementation first"`.

### 4.2 Describe / Context / It structure (exactly 10 Its)

```powershell
Describe "BugFreeUmbrella Module" -Tag 'Module' {

    Context "Manifest" {

        It "manifest file exists at src/BugFreeUmbrella/BugFreeUmbrella.psd1" {
            Test-Path -LiteralPath $manifestPath | Should -Be $true
        }

        It "manifest version is 5.0.0 (matches CHANGELOG next)" {
            $manifest = Import-PowerShellDataFile -Path $manifestPath
            $manifest.ModuleVersion | Should -Be '5.0.0'
        }

        It "manifest declares PowerShellVersion 7.0+ and no hardcoded secrets" {
            $manifest = Import-PowerShellDataFile -Path $manifestPath
            [version]$manifest.PowerShellVersion | Should -BeGreaterOrEqual ([version]'7.0')
            $raw = Get-Content -LiteralPath $manifestPath -Raw
            $raw | Should -Not -Match '(?i)(api[_-]?key|secret|password)\s*=\s*[''"][^''"]+[''"]'
        }

        It "Test-ModuleManifest passes without error" {
            { Test-ModuleManifest -Path $manifestPath -ErrorAction Stop | Out-Null } | Should -Not -Throw
        }
    }

    Context "Import" {

        It "imports via Import-Module src/BugFreeUmbrella without error on Ubuntu" {
            { Import-Module $manifestPath -Force -ErrorAction Stop } | Should -Not -Throw
            (Get-Module BugFreeUmbrella) | Should -Not -BeNullOrEmpty
        }

        It "exposes Get-Command count matching catalog totalScripts (358)" {
            $catalog = Get-Content -LiteralPath $catalogPath -Raw | ConvertFrom-Json
            $expected = $catalog.totalScripts  # 358 on 2026-08-20
            $exported = (Get-Command -Module BugFreeUmbrella).Count
            $exported | Should -Be $expected -Because "module should re-export one function per catalog entry"
            # If DesignModule instead exports only Get-BUScript/Invoke-BUScript shims,
            # update this It to: (Get-Command -Module BugFreeUmbrella -Name Get-BUScript,Invoke-BUScript).Count | Should -Be 2
            # and move the 358 assertion to Catalog.Tests.ps1 (see section 5). Document the choice.
        }
    }

    Context "Loader hygiene" {

        It "loader dot-sources only from src/BugFreeUmbrella/Public and Private" {
            $loader = Get-Content -LiteralPath $loaderPath -Raw
            $loader | Should -Match 'Public'
            $loader | Should -Not -Match '\.\.[/\\]scripts'
        }

        It "loader has comment-based help and CmdletBinding where applicable" {
            $loader | Should -Match '\.SYNOPSIS'
        }

        It "PSScriptAnalyzer reports 0 Errors on BugFreeUmbrella.psm1" {
            $settings = Join-Path $repoRoot '.vscode/PSScriptAnalyzerSettings.psd1'
            $findings = Invoke-ScriptAnalyzer -Path $loaderPath -Settings $settings -ErrorAction Stop
            $errors = @($findings | Where-Object Severity -eq 'Error')
            $errors | Should -BeNullOrEmpty -Because ($errors | Format-Table RuleName,Line,Message -AutoSize | Out-String)
        }
    }

    Context "Export surface" {

        It "all exported commands use Approved Verbs" {
            $verbs = (Get-Verb).Verb
            $bad = Get-Command -Module BugFreeUmbrella | Where-Object Verb -NotIn $verbs
            $bad | Should -BeNullOrEmpty
        }
    }
}
```

**Count:** 4 + 2 + 3 + 1 = **10 `It`**.

### 4.3 Ubuntu edge — mocking strategy

CI runs on `ubuntu-latest`. The module may probe `Out-GridView`, `Import-Module ActiveDirectory`, `Get-CimInstance Win32_*`. Tests MUST NOT require a Windows host:

* Use `Mock Get-Command { $true } -ParameterFilter { $Name -eq 'Out-GridView' }` or stub `function Out-GridView { param($InputObject) $InputObject }` in a `BeforeAll` scoped to the import Context.
* Prefer Pester `Mock` over global function definition where possible, so the real environment is restored in `AfterAll`.
* If the loader touches `HKLM:\` or `C:\Windows`, mock `Test-Path`/`Get-ItemProperty` accordingly.
* Never mock `Import-Module` itself.

### 4.4 Failure messages

* Manifest missing → `"Module manifest not found at $manifestPath — did DesignModule run? src/BugFreeUmbrella/BugFreeUmbrella.psd1 absent."`
* Version mismatch → `"Expected ModuleVersion 5.0.0 but found $($manifest.ModuleVersion) — bump CHANGELOG and manifest together."`
* Count mismatch → `"Get-Command count $exported does not match catalog totalScripts $expected — re-run tools/Build-Catalog.ps1 or adjust export surface."`

## 5. Tests/Catalog.Tests.ps1 — 8 Its

### 5.1 Header and scaffolding

```powershell
#Requires -Modules Pester

<#
.SYNOPSIS
    Validates scripts/.catalog/metadata.json integrity and Build-Catalog -Validate.

.DESCRIPTION
    Asserts the catalog generated by tools/Build-Catalog.ps1 is well-formed,
    sorted, prefixed, and not stale. The -Validate check is the CI gate for drift.
#>

BeforeAll {
    $repoRoot    = (Resolve-Path (Join-Path $PSScriptRoot '..')).Path
    $catalogPath = Join-Path $repoRoot 'scripts/.catalog/metadata.json'
    $buildPath   = Join-Path $repoRoot 'tools/Build-Catalog.ps1'
    $catalog     = Get-Content -LiteralPath $catalogPath -Raw | ConvertFrom-Json
}
```

### 5.2 Describe / Context / It structure (exactly 8 Its)

```powershell
Describe "Script Catalog" -Tag 'Catalog' {

    Context "File integrity" {

        It "metadata.json exists and parses as JSON" {
            Test-Path -LiteralPath $catalogPath | Should -Be $true
            { Get-Content -LiteralPath $catalogPath -Raw | ConvertFrom-Json | Out-Null } | Should -Not -Throw
        }

        It "totalScripts is 358 and matches scripts array length" {
            $catalog.totalScripts | Should -Be 358
            @($catalog.scripts).Count | Should -Be 358
        }

        It "every entry has required fields (path, name, category, synopsis, hasCmdletBinding)" {
            foreach ($e in $catalog.scripts) {
                $e.path             | Should -Not -BeNullOrEmpty
                $e.name             | Should -Not -BeNullOrEmpty
                $e.category         | Should -Not -BeNullOrEmpty
                $e.synopsis         | Should -Not -BeNullOrEmpty
                $e.hasCmdletBinding | Should -Not -BeNullOrEmpty
            }
        }
    }

    Context "Ordering and paths" {

        It "scripts are sorted lexicographically by path" {
            $paths = @($catalog.scripts.path)
            $sorted = @($paths | Sort-Object)
            $paths | Should -Be $sorted
        }

        It "every path starts with 'scripts/' and ends with '.ps1'" {
            foreach ($e in $catalog.scripts) {
                $e.path | Should -Match '^scripts/.+\.ps1$'
            }
        }

        It "no duplicate paths exist" {
            $paths = @($catalog.scripts.path)
            $paths.Count | Should -Be (@($paths | Sort-Object -Unique).Count)
        }
    }

    Context "Freshness gate" {

        It "Build-Catalog -Validate passes (catalog not stale)" {
            $out = & $buildPath -Validate 2>&1
            $LASTEXITCODE | Should -Be 0 -Because "Run 'pwsh -File tools/Build-Catalog.ps1' to regenerate. Output: $out"
        }

        It "categories are non-empty and match path-derived category" {
            foreach ($e in $catalog.scripts) {
                $derived = ($e.path -replace '^scripts/', '' -replace '/[^/]+\.ps1$', '') -replace '\\','/'
                $e.category | Should -Be $derived -Because "category should mirror directory of $($e.path)"
            }
        }
    }
}
```

**Count:** 3 + 3 + 2 = **8 `It`**.

### 5.3 Stale catalog edge — failure message contract

When `-Validate` fails, the It MUST surface:

```
"Catalog stale — Run 'pwsh -File tools/Build-Catalog.ps1' to regenerate. Diff: …"
```

Implementation should capture both stdout and stderr from `& $buildPath -Validate` and include it in `Should -Be 0 -Because`.

### 5.4 Category derivation nuance

Some scripts live at `scripts/<category>/...` while proactive remediations will move under `scripts/endpoints/remediation/` in 5.0 (DesignReorg). The test uses the derived directory portion, so it remains green before and after the reorg. Do not hardcode the set of categories.

* Argument completer is registered via `Register-ArgumentCompleter -CommandName Get-BUScript,Invoke-BUScript -ParameterName Category -ScriptBlock { … }` (DesignCLI). Tests verify registration without invoking the completer UI.

### 6.2 Describe / Context / It structure (exactly 8 Its)

```powershell
Describe "Umbrella CLI" -Tag 'CLI' {

    Context "Discovery — Get-BUScript" {

        It "Get-BUScript -Search 'intune' returns 35 scripts" {
            $hits = Get-BUScript -Search 'intune'
            @($hits).Count | Should -Be 35
        }

        It "Get-BUScript -Category 'cloud' returns 16 scripts" {
            $hits = Get-BUScript -Category 'cloud'
            @($hits).Count | Should -Be 16
        }

        It "Get-BUScript -Search is case-insensitive and matches path/synopsis/category" {
            $a = Get-BUScript -Search 'Intune'
            $b = Get-BUScript -Search 'intune'
            @($a).Count | Should -Be @($b).Count
            @($a | Where-Object { $_.path -match 'intune' -or $_.synopsis -match 'intune' -or $_.category -match 'intune' }).Count | Should -Be @($a).Count
        }

        It "Get-BUScript without filters returns all 358 scripts" {
            $all = Get-BUScript
            @($all).Count | Should -Be 358
        }
    }

    Context "Invocation — Invoke-BUScript" {

        It "Invoke-BUScript -WhatIf previews without executing" {
            $target = (Get-BUScript -Search 'intune' | Select-Object -First 1).path
            { Invoke-BUScript -Path $target -WhatIf } | Should -Not -Throw
        }

        It "Invoke-BUScript validates path exists and category prefix" {
            { Invoke-BUScript -Path 'scripts/nonexistent/Foo.ps1' } | Should -Throw -ExpectedMessage '*not found*'
            { Invoke-BUScript -Path 'scripts/cloud/containers/Foo.ps1' -Category 'intune' } | Should -Throw
        }
    }

    Context "Completer and interactive fallback" {

        It "argument completer is registered for -Category on Get-BUScript and Invoke-BUScript" {
            $completers = (Get-ArgumentCompleter -CommandName Get-BUScript -ParameterName Category) +
                          (Get-ArgumentCompleter -CommandName Invoke-BUScript -ParameterName Category)
            $completers | Should -Not -BeNullOrEmpty
        }

        It "-Interactive falls back to console menu when Out-GridView is absent (Ubuntu)" {
            Mock Out-GridView { throw "Out-GridView not available on this platform" } -ModuleName BugFreeUmbrella
            Mock Read-Host { return '1' } -ModuleName BugFreeUmbrella
            { Get-BUScript -Interactive } | Should -Not -Throw
            Should -Invoke Read-Host -ModuleName BugFreeUmbrella -Times 1
        }
    }
}
```

**Count:** 4 + 2 + 2 = **8 `It`**.

> **Note on counts 35/16:** These are the current catalog-derived expectations for `-Search intune` and `-Category cloud` on the 358-script snapshot. If the catalog grows before Implementation, Implementation MUST regenerate counts via `(Get-BUScript -Search 'intune').Count` and update the `Should -Be` literals, or parameterize them as `Should -BeGreaterOrEqual 30` with a comment explaining the snapshot.

### 6.3 Completer — implementation contract (DesignCLI dependency)

DesignCLI must ensure:

```powershell
Register-ArgumentCompleter -CommandName Get-BUScript, Invoke-BUScript -ParameterName Category -ScriptBlock {

# Cross-platform: Out-GridView probe via Get-Command Out-GridView -ErrorAction SilentlyContinue
# If absent, fall back to: numbered Write-Host list + Read-Host "Select [1-N]"
```

CLI tests must not assume Windows — they mock `Out-GridView` and `Read-Host` as shown.

### 6.4 Interactive fallback — edge

* On Ubuntu, `Out-GridView` is absent. Code must do `if (Get-Command Out-GridView -ErrorAction SilentlyContinue) { … | Out-GridView -PassThru } else { Show-ConsoleMenu }`.
* Tests mock `Out-GridView` to throw and assert `Read-Host` is invoked exactly once.
* `Show-ConsoleMenu` must handle empty result (user presses Enter) by returning `$null` without throwing.

## 12. Implementation Notes for the Engineer

* Keep each `It` focused on a **single assertion** — one `Should` per `It` where possible, so failures are pinpointed. Use `-Because` to explain the expectation.
* Use `BeforeAll` for expensive work (`Import-PowerShellDataFile`, `ConvertFrom-Json`) and `BeforeEach` for mocks that must be fresh per `It`.
* Prefer `Should -Be $expected -Because …` over `Should -BeExactly` unless casing matters.
* For file-content assertions (loader hygiene, manifest secrets), read the file once in `BeforeAll` into a `$raw` variable rather than per-`It`.
* All `Mock` calls that target module code must specify `-ModuleName BugFreeUmbrella` so they bind to the module's session state.
* Do not add `Tag 'Integration'` to any of the 26 new `It` blocks — they must run in the default `ExcludeTag = @('Integration')` pass.
* Ensure each new file is `UTF-8 with BOM`, `CRLF`, `4-space` indent, and passes `Invoke-ScriptAnalyzer -Settings .vscode/PSScriptAnalyzerSettings.psd1` with `0 Errors`.
