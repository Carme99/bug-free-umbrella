# Script Examples

This directory contains practical, real-world examples of how to use the scripts in this repository for common IT workflows and scenarios.

## Directory Structure

```
examples/
├── onboarding/         - New employee and device onboarding workflows
├── maintenance/        - Regular maintenance and health check procedures
├── incident-response/  - Security incident and troubleshooting scenarios
├── compliance/         - Compliance auditing and reporting workflows
└── automation/         - Automated scheduling and CI/CD integration
```

## How to Use These Examples

1. **Review the scenario** - Each example includes a description of the use case
2. **Check prerequisites** - Verify you have required permissions and modules
3. **Customize parameters** - Adjust paths, thresholds, and settings for your environment
4. **Test first** - Always test in non-production before deploying

## Example Categories

### Onboarding
Common workflows for setting up new users and devices:
- New employee workstation setup
- Application deployment bundles
- Initial compliance configuration
- User profile preparation

### Maintenance
Regular operational tasks:
- Daily health checks
- Weekly system maintenance
- Monthly compliance audits
- Quarterly reviews

### Incident Response
Troubleshooting and security scenarios:
- **security-incident-response.ps1** - Comprehensive security breach investigation workflow
- **performance-degradation-investigation.ps1** - System performance diagnostics and troubleshooting
- Service outage diagnostics
- Data recovery procedures

### Compliance
Audit and compliance workflows:
- Multi-framework compliance scanning
- BitLocker compliance verification
- Security posture assessments
- Audit report generation

### Automation
Scheduled task and CI/CD examples:
- **scheduled-daily-reporting.ps1** - Automated daily compliance and health reporting with email delivery
- **register-scheduled-tasks.ps1** - Bulk Task Scheduler registration for all monitoring workflows
- Automated health monitoring
- Email reporting workflows
- Integration with monitoring systems
